# Project Management Dashboard & Task Tracking System

## Overview

This project is an Excel-based Project Management Dashboard designed to monitor project activities, track task progress, analyze project performance, and visualize timelines. The dashboard provides project-level insights through KPIs, charts, and interactive reporting features commonly used in project coordination and management roles.

## Features

* Task tracking and status monitoring
* Project progress and completion rate analysis
* Priority-wise task distribution reporting
* Resource allocation and workload tracking
* Interactive Pivot Charts and KPI Dashboard
* Data validation and conditional formatting
* Gantt Chart for project timeline visualization
* Automated project reporting and performance monitoring

## Dashboard Metrics

* Total Tasks
* Completed Tasks
* In Progress Tasks
* Pending Tasks
* Project Completion Percentage
* Priority Distribution
* Resource Workload Analysis

## Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Validation
* Conditional Formatting
* Gantt Charts

## Project Structure

* **Task_Tracker** – Raw project and task data
* **Project_Dashboard** – KPI dashboard and visual reports
* **Project_Timeline** – Gantt chart and project schedule visualization

## Business Use Case

The dashboard helps project teams monitor ongoing activities, track deadlines, identify pending tasks, and support project reporting and coordination. It provides a centralized view of project performance and resource utilization for effective decision-making.
